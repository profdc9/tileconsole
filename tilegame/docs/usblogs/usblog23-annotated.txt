usblog23 annotated.  Hardware: RP2350 USB host, one bus-powered full-speed-driven hub (hub address 6), a full-speed XInput gamepad (hub port 3),

### Summary
Same hub, same two devices, same board, same session:
  - gamepad enumerated first, keyboard second  -> the keyboard's control requests are lost, the controller retries for ever (TinyUSB 0.18).
  - keyboard enumerated first, gamepad second  -> everything enumerates, and both keep working.
In earlier logs (usblog15, 16, 17) the keyboard was in a higher-numbered hub port than the gamepad, so each host restart re-enumerated
the gamepad first again and the keyboard failed again; that is why the restarts there did not help.
